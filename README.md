[![Packaging status](https://repology.org/badge/tiny-repos/carapace-gcloud.svg)](https://repology.org/project/carapace-gcloud/versions)

Carapace-gcloud is an enriched completer for [gcloud-cli].

## Getting Started

With [carapace-bin] `carapace-gcloud` is implicitly used when the binary is in [PATH].

Otherwise [source](https://carapace-sh.github.io/carapace/carapace/gen.html#hidden-subcommand) the output of `carapace-gcloud _carapace`.

[gcloud-cli]:https://cloud.google.com/sdk/gcloud
[carapace-bin]:https://github.com/carapace-sh/carapace-bin
[carapace]:https://carapace.sh
[PATH]:https://en.wikipedia.org/wiki/PATH_(variable)
